Essential Stash Commands Cheat Sheet
git stash: Instantly stashes your work with a generic autogenerated message.

git stash list: Displays all the items currently sitting inside your locker, along with their unique index numbers (e.g., stash@{0}).

git stash apply: Restores your stashed code but keeps a copy of it inside the stash locker as a backup.

git stash pop: Restores your stashed code and permanently deletes it from the stash list to keep things clean.

git stash drop stash@{0}: Manually deletes a specific stashed item without applying it to your files.

git stash -u: Stashes everything, including brand-new untracked files that you haven't run git add on yet.
